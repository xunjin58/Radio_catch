# 广东香水柠檬带货口播（Script-First）

用于起草一份候选口播，不负责剪辑、TTS、字幕渲染或发布。规则唯一权威为 `backend/prompts/copywriting_xiaohongshu.md`，本文件只定义执行方法。第一稿必须经主代理按画面能力、用户确认商品资料和实测时长审核后才可交付 TTS。

## 输入

每条视频需要：已审核素材的汇总 `shot_capabilities`、当前项目柠檬品类已确认的商品卖点池、目标时长，以及用户指定语气或 CTA（如有）。卖点一经用户确认并记录来源，同一项目的后续柠檬批次直接复用，不重复询问；用户明确更正、替换或切换品类时才更新。无需先取得成片级 MiMo 看片；它只可作为 `--analyze-only` 复核入口。

## 起草方法

1. 先读能力清单与用户卖点池，确定可以作为画面事实断言的卖点；不要按镜头逐句写。画面动作只用于校验和选片，不能写入口播。
2. 写一段连续的姐妹视角安利：从自然的钩子或生活场景进入，选择少量卖点推进，再以轻 CTA 收束。每段优先补充“为什么值得、和什么比、什么时候会想吃/喝”；情绪/场景/CTA 只需不与画面矛盾。
3. 逐项标注文中的事实断言，并为每项给出能力证据。价格、产地等用户确认事实标记为用户确认来源，不伪装成画面证据。
4. 同批草稿的开头、价格句式、卖点推进顺序和收尾都要错开。禁用“谁懂啊 / 家人们 / 救命 / 真的绝了 / 捡到宝 / 续命 / 冲吧”，感叹号最多 1 个。
5. 禁止解说正在发生的画面动作：不写“我现在拿起 / 我切开 / 一刀下去 / 倒进杯子里”等。字幕按最终可读节奏拆，不要求句序等于镜头顺序；每段 ≤14 个可见字符、单行。

起草引擎不限（MiMo、DeepSeek Agent 等），但不能改变规则文档或绕过事实校验。

## 交付格式

```text
video_id: <video_id>
口播: <一份完整的连续安利>
fact_assertions:
- <事实断言>：<shot_capability>，或“用户确认商品资料”
evidence:
- <事实断言>：<支撑该事实的 clip_id 与 capability>
product_facts:
- <实际使用的用户确认卖点>：<确认来源>
字幕切分建议:
- <每段不超过 14 个可见字符的 cue>
```

主代理按能力证据、同批差异化、渲染后的实测时长和用户确认完成定稿；不得把第一版草稿直接用于 TTS。
