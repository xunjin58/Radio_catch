# 交接说明

## 当前可用范围

- 后端有 35 条本地 API 路由，覆盖健康检查、模型配置、项目级业务背景、媒体处理、素材审核、实验/成片、任务、指标导入和分析。
- 已验证真实 FFmpeg 闭环：视频上传、异步抽帧、人工审核、11 秒纵版 MP4 导出、72 小时 CSV 导入和规律查询。
- 前端已接入真实 API：素材库筛选、审核写回、带货镜头角色修正、受控实验创建与导出、成片下载、CSV 回传、规律查询、模型配置和商家业务背景均可从界面完成。

## 已知边界

- V1 不自动登录或发布抖音，不管理多账号。
- 前端不再使用演示素材或虚构统计数据；个别高级能力（时间线拖拽编辑、批量审核、模型配置编辑/删除）仍可通过 API 使用，尚未提供对应界面。
- OpenAI 兼容模型使用已保存的关键帧；启用原生视频能力的 Gemini 与 MiMo 配置会按其媒体限制直接发送原始视频和内嵌音轨。三种理解路径均使用项目级业务背景，且背景不能替代画面或音频证据。
- 媒体处理使用本进程任务池，适用于单人本地部署；若扩展到多进程或多人，应替换为持久队列与对象存储。

## 建议的下一步

1. 为原生视频模型补充成本统计和真实供应商回归验证。
2. 补充时间线拖拽编辑、批量审核和模型配置编辑/删除界面。
3. 使用真实发布数据运行不少于 3 组独立对照实验后，再将候选结论升级为已验证规律。
